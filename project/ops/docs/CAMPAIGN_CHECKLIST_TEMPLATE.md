# Campaign Checklist Template (7ya.io)

Use this checklist for every campaign that starts on 7ya.io and then propagates to platform channels.

## Campaign metadata

- Campaign name:
- Campaign slug:
- Campaign owner:
- Primary goal (traffic, leads, bookings, authority):
- Primary CTA: Manage 7ya.io (`https://7ya.io`)
- Campaign window (start/end):

## 1) Canonical page readiness (7ya.io)

- [ ] Canonical page draft created on 7ya.io
- [ ] Headline and subheadline approved
- [ ] Primary CTA and fallback CTA validated
- [ ] Mobile/desktop QA complete
- [ ] Schema/meta/Open Graph tags reviewed
- [ ] Publish URL finalized

## 2) Tracking and links

- [ ] UTM links generated for each destination platform
- [ ] UTM values follow the project convention template
- [ ] Canonical URL validated in all shared links
- [ ] Link shorteners (if used) mapped to source links
- [ ] Analytics event capture verified (`lead_submitted`, `booking_requested`, `newsletter_subscribed`)

## 3) Platform packaging

- [ ] X/Twitter copy approved
- [ ] LinkedIn copy approved
- [ ] Instagram/TikTok captions + hashtags approved
- [ ] YouTube title/description/thumbnail approved
- [ ] Telegram/community post variant approved
- [ ] Bilingual variants prepared where applicable (Hebrew/English)

## 4) Scheduling and publish

- [ ] Publish date/time confirmed for all selected platforms
- [ ] 24-48h coordinated publish window planned
- [ ] Owner and backup publisher assigned
- [ ] Comments/DM response owner assigned
- [ ] Uptime check of 7ya.io completed before launch

## 5) Post-publish monitoring

- [ ] First-hour link + CTA checks completed
- [ ] First 24h analytics snapshot captured
- [ ] Third-party mentions logged
- [ ] Platform deltas recorded versus baseline
- [ ] Gaps and opportunities added to weekly report

## 6) Campaign closeout

- [ ] 7-day performance summary completed
- [ ] Top assets and winning messages documented
- [ ] Underperforming assets tagged with root cause
- [ ] Next-iteration actions created and assigned
